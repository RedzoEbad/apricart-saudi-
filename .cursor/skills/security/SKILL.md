# Security Skill
For every feature, identify:
- authentication
- authorization/RBAC
- tenant/resource isolation
- input validation
- injection
- SSRF
- XSS
- file upload/path traversal
- secrets/cryptography
- rate limiting/replay/idempotency
- dependency/supply-chain risk
- database permissions
- logging/auditability
- business-logic abuse

For protected APIs test 401, 403, allowed access, cross-tenant access and privilege escalation.
Do not modify security controls merely to make tests pass.
