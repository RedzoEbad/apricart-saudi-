# Feature Development Skill (Apricart Backend)
1. Read Jira requirements, relevant source code, tests and architecture.
2. Create/update `plans/<JIRA-ID>-<feature>.md`.
3. Identify API, DB, RBAC, security and dependency impact.
4. Implement incrementally using existing Spring Boot patterns.
5. Add unit tests under `src/test/java/.../unit/`.
6. Add integration tests under `src/test/java/.../integration/` where boundaries change.
7. Run `mvn -B verify`.
8. Perform security and code review.
9. Confirm acceptance criteria.
10. Prepare PR with Jira reference and testing evidence.
